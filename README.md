# Animations

Low-poly "What if..." animations.

- `skills/` — saved agent skills for this work (Remotion, Three.js, Blender, sound). See `skills/README.md`.
- `scripts/` — video scripts: `what-if-air-disappeared.md`, `what-if-gravity-flipped.md`.
- `video/` — Remotion + Three.js project that renders the videos. See `video/README.md`.
- `renders/` — finished videos.
