# Сценарий для чтения и передачи

[Шаблон Markdown](scenario.md) пригоден для читки и раскадровки. Для сборки сложи те же данные в JSON по [схеме сценария v1](scenario.schema.json). Держи реплики, границы сцен и источники одинаковыми в обеих версиях. [Пример расчёта длительности и сверки](../references/production.md)

| Поле JSON | Что записать |
| --- | --- |
| `idea_id` | ID из пакета генератора идей или `null` для самостоятельного брифа. |
| `duration`, `scenes` | Секунды от начала ролика, сцены по порядку. Начало включительно, конец совпадает с началом следующей сцены. `fps` появляется при наличии выбранной композиции. Конец последней сцены равен `total_s`. |
| `selected_hook` | Описание первого кадра и точное начало первой реплики, если хук произносится. Для визуального хука `spoken` равен `null`. |
| `voice` | В режиме `single` один говорящий, `clean_text` — текст для отправки выбранной модели. В режиме `dialogue` `clean_text` читается как единая расшифровка, а `dialogue` повторяет реплики по порядку и добавляет `voice_id` к репликам после назначения голосов. В режиме `none` `clean_text` равен `null`, а массивы `voice_lines` пусты. `settings` хранит применимые к выбранной модели настройки голоса из брифа. |
| `overlays` | Точный текст, назначение и подсказка для момента появления или смены значения. Для счётчика укажи исходное и новое значения по сценам. |
| `sources` | По записи на связь утверждения с источником. Для собственного расчёта укажи `calculation`, запиши выкладки и единицы в `notes`. `url` может быть `null` для расчёта на основе уже заданных величин. |
| `fictional_assumptions`, `constraints` | Границы вымысла и договорённости для команды. |
| `recheck_before_publication` | Сведения из пакета идеи или текущей проверки, которые могут устареть до публикации. Добавь срок повторной проверки и условия пересмотра, если они известны. |

В статусе `preliminary` границы сцен оценочные. После сверки с аудио укажи `aligned`, фактическую длину голоса в `duration.audio_s`, при смещении `voice.audio_offset_s` и фактические границы каждой реплики в `voice_lines`. Границы реплик отсчитываются от старта ролика. Реплика может продолжаться за склейкой, если соседняя сцена оставляет для неё место. Если нужны отдельные привязки внутри реплики, приложи метки слов с помощью `voice.alignment_ref`. У ролика без речи `aligned` означает сверку по аниматику, а поля длительности голосовой дорожки опускаются.

Проверь связь полей стандартным Python 3 из корня репозитория. Проверка читает JSON и ищет разрывы сцен, несогласованную длительность, расхождения в тексте и ошибки звуковых привязок. Совместимость полей со схемой можно проверить отдельно любым валидатором JSON Schema Draft 2020-12.

```sh
python3 skills/viral-scriptwriter/scripts/check_script.py путь/к/сценарию.json
```
