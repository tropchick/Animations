# Проверка генерации идей

Дата прогонов — 27 ноября 2026 года. Идеи оценивались по текстовым карточкам, до производства. Возраст публикаций, численные метрики и длительности в аналитической фикстуре заданы для упражнения.

## Общий офлайн-запрос

> Без интернета придумай пять разных идей на русском для коротких вертикальных 3D-анимаций для TikTok, YouTube Shorts и Instagram Reels, 20–35 секунд. Две идеи должны быть связаны с игровой культурой, остальные темы свободные. Для каждой укажи название, хук, суть, развитие с концовкой, главный кадр, интерес для зрителя и сложность. Избегай шуток о внешности, весе и физических особенностях реальных людей.

| Прогон | Доступный контекст |
| --- | --- |
| [A. Обычный запрос](runs/plain.md) | Только общий текст запроса, отдельная сессия |
| [B. Скилл](runs/skill-only.md) | Тот же запрос, SKILL.md, методики генерации и оценки. База и материалы канала закрыты для этого прогона |
| [C. Скилл и база](runs/skill-channel.md) | Тот же запрос, скилл и JSON с разборами 17 роликов. Отдельный текстовый разбор в момент запуска был ещё недоступен |

Каждый вариант получил одинаковые требования к числу карточек, хронометражу, платформам, игровым темам и ограничениям на юмор. Для офлайн-прогонов запрет на поиск был частью задания. Это проверка поведения при отсутствии доступа к интернету, доступ сети целиком не отключался.

## Рубрика сравнения

Оригинальность и визуальный потенциал оценивались по каждой карточке. Для этих двух колонок в таблице приводится среднее по пяти идеям. Разнообразие и соответствие каналу оценивались по подборке целиком. Шкала от 1 до 5 отражает редакторское суждение.

| Критерий | 1 | 3 | 5 |
| --- | --- | --- | --- |
| Оригинальность | Знакомый сюжет с косметической заменой | Есть собственное правило, конфликт или развязка | Незаменимые правило и развязка создают узнаваемую отдельную концепцию |
| Разнообразие | Сюжеты отличаются главным образом декорациями | Несколько форм повествования, часть действий повторяется | Разные темы, действия зрителя, способы развития и типы развязок |
| Визуальный потенциал | Опора на рассказ или подпись | Сцена читается и содержит один сильный кадр | Сами движения объясняют развитие и исход истории в вертикальном кадре |
| Соответствие каналу | Нет убедительной связи с опытом канала или есть прямые повторы | Есть отдельные переносимые приёмы, выводы по аудитории ограничены | Несколько уместных приёмов из истории применены к существенно новым темам и действиям |

## Результаты сравнения

Другой агент оценивал три анонимизированные подборки. Он получил одинаковое краткое описание особенностей канала для критерия соответствия. Вводные и комментарии, по которым можно определить условия прогонов, убрали из карточек для оценки.

| Прогон | Оригинальность, среднее | Разнообразие | Визуальный потенциал, среднее | Соответствие каналу |
| --- | ---: | ---: | ---: | ---: |
| A. Обычный запрос | 3,8 | **5** | 4,4 | 3 |
| B. Скилл | **4,0** | 4 | **4,6** | **5** |
| C. Скилл и база | 3,8 | 3 | 4,4 | 4 |

В порядке карточек оценки «оригинальность / визуал» составили: A — 3/4, 4/5, 4/5, 4/4, 4/4. B — 5/5, 4/4, 4/5, 4/5, 3/4. C — 3/5, 4/4, 4/4, 3/4, 5/5.

- **A.** Самая широкая смена действий и тонов, от гоночного короткого пути до тихой истории города в капле. В части развязок вопрос и проверка исхода менее ясны, чем главный образ.
- **B.** Видимые цели вроде щели в мосту и высоко расположенного звонка дают зрителю возможность предсказать решение. «Мост из полоски здоровья» получил 5/5 по оригинальности и визуалу. Разница средних с A и C равна одному баллу в сумме пяти карточек по каждому из двух критериев.
- **C.** Агент явно перенёс из гонки релизов общую точку финиша. Идея «Лужа на три секунды вперёд» получила 5/5 за один кадр, показывающий причину и результат одновременно. Повтор дворовых декораций и сюжетов с поиском сократил разнообразие. Мотив призрака на трассе независимо возник во всех трёх прогонах.

База помогла объяснить конкретное творческое решение, а итоговая подборка уступила B по редакторской оценке соответствия. Один запрос, один прогон на условие и один оценщик дают диагностический пример. Из этого сравнения нельзя вывести устойчивое превосходство скилла или влияние базы на зрительские реакции. Для C формулировку проверки развития в основной инструкции уточнили, чтобы она допускала смену смысла внутри одного кадра. Аудиторного теста и рендера карточек не было.

## Технические проверки

- Проверены YAML-метаданные скилла, относительные ссылки, JSON-схемы, примеры и ссылки на исходники всех 17 роликов.
- CSV и JSON проверены на временных копиях. Предварительный просмотр оставил файл без изменений. После записи повторный импорт распознал уже существующие снимки. Явный ноль сохранился, пустое значение осталось неизвестным. Для эквивалентных часовых поясов получился один идентификатор снимка.
- Пакет с ошибочной строкой не изменил базу. Конфликт значений обновлялся только с явным исправлением. Десять конкурентных импортов сохранили все снимки. Рабочая база осталась без вымышленных метрик.
