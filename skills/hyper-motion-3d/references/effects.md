# Пространственные эффекты

Компоненты из [effects.tsx](../examples/effects.tsx) работают внутри `ThreeCanvas`. Они принимают мировые или локальные координаты родительской группы. Проектируй общий источник, форму движения и последовательность пространственных слоёв. Контакт считывается по сжатию позы, волне вдоль поверхности, траекториям фрагментов и реакции соседних объектов. Возьми число слоёв из истории и глубины кадра. [Система слоёв](layered-vfx.md) · [Хореография](effect-choreography.md) Отдай выделению лица и субтитрам собственную область кадра.

## Общие параметры

| Параметр | Единицы и поведение |
| --- | --- |
| `frame`, `from`, `duration` | Кадры одной шкалы, окно `[from, from + duration)`. Без `frame` читается локальный кадр Remotion. Для независимой шкалы сцены передай кадр явно. Если длительность опущена, конечные эффекты получают свой интервал с учётом FPS. |
| `position`, `direction` | Координаты и вектор из трёх чисел. У кольца, скобок, атмосферной карточки и искажений `direction` задаёт нормаль плоскости. У стрелки и выброса задаёт направление движения. |
| `size`, `opacity`, `intensity` | Масштаб в единицах сцены, прозрачность 0–1, множитель выразительности 0–2. Частицы и следы интерпретируют размер по таблице. |
| `motion`, `seed` | `soft` смягчает начало и остановку, `linear` даёт равномерное перемещение, `sharp` быстро набирает дистанцию. Параметр управляет ходом эффекта, если он строится по локальному прогрессу. `seed` привязывает рисунок к событию. |
| `theme` | Встроенные `low-poly`, `clay` или объект `{color, accent, finish, roughness?}`. `finish` принимает `faceted`, `sculpted` и `graphic`. |
| `color`, `budget` | Индивидуальный цвет и выделенный этому событию лимит частиц, сегментов или колец. При уменьшении бюджета набор сохраняет координаты оставшихся частиц. |

Встроенные стили рассчитывают освещение от сцены. Для пластилина используй шероховатые цвета света и реквизита, скульптурные облака, толстые дуги и небольшие гранулы. Квантуй `frame` по экспозициям персонажа, если эффект должен выглядеть как предмет, переставляемый вручную. Камера, надписи и звук могут сохранять полный выходной FPS. Для новых стилей передай подходящий набор цветов и материал через `theme`. [Материалы пластилиновой сцены](../../claymation-3d/references/materials-geometry.md).

## Выбор компонента

| Эффект | Применение и настройки |
| --- | --- |
| `SpeedLines` | Разгон, короткий пролёт. Вытянутые конические штрихи оставляют коридор вдоль `direction`. `size` задаёт ширину коридора и масштаб штрихов, `count` управляет плотностью. |
| `MotionTrail` | Показать траекторию. Передай чистую `sample(frame)`, `step` между отсчётами, `samples`, `sampleFrom`. `size` задаёт толщину, а история вычисляется прямыми запросами к траектории. |
| `Shockwave` | Читаемое распространение удара или сигнала. `size` задаёт внешний радиус, `direction` по умолчанию смотрит вверх, `rings` задаёт 1–4 фронта, `thickness` масштабирует толщину колец в диапазоне 0,1–3. |
| `ParticleBurst` | Фрагменты материала. `count`, полный угол конуса `spread` в градусах и `gravity` управляют набором и дугами движения. |
| `AmbientParticles` | Тихое движение в воздухе. `bounds` задаёт полные размеры объёма, `direction` управляет скоростью и направлением дрейфа, `size` масштабирует гранулы. Эффект с опущенным `duration` остаётся в сцене. |
| `DustCloud` | Низкий широкий всплеск в контакте с землёй. Сдвинь начало к точке касания, подбери `color` под площадку. При горизонтальной плоскости оставь направление по умолчанию. |
| `CartoonSmoke` | Поднимающиеся клубы за объектом. Поддерживает `count` и `spread`. Для глиняных клубов используй прохладные и тёплые значения цвета окружения. |
| `EnergyRing` | Набор энергии или подтверждение действия. Две дуги вращаются вокруг заданной нормали, `size` задаёт радиус. |
| `EnergyAura` | Контурный свет вокруг объёма. Установи `size` немного выше радиуса объекта. В пресете clay эффект становится парой материальных дуг. |
| `ImpactEffect` | Согласованные волна и искры у источника. Остальные слои удобно синхронизировать по одному событию таймлайна. |
| `ObjectHighlight` | Маркировка четырьмя угловыми скобами. `size` задаёт полупролёт, `direction` поворачивает плоскость. |
| `Sparkles` | Несколько светлых геометрических штрихов на отражающей кромке. Меняй `spread` под угол поверхности. |
| `MotionSmear` | Высокоскоростная промежуточная форма по двум отсчётам `sample(frame)`. Дай свою нейтральную геометрию, вытянутую вдоль локальной +Y, через `children` или `renderSmear(opacity)`. |
| `DistortionEffect` | Локальная рябь в плоскости. Передай `map` для мягкой деформации UV собственной текстуры. Без текстуры шейдер строит поле линий. Размести плоскость там, где зритель должен увидеть линзу или волну. |
| `LightSweep` | Движущийся световой акцент по сферической оболочке. Для другой формы передай центрированную геометрию с координатами порядка ±1 и используй `size` для совпадения с поверхностью. |
| `AtmosphericEffect` | Задняя карточка `haze` или `rays` с плавной границей. Поставь за персонажем, закрепи по направлению источника света. `size` задаёт полувысоту. Эффект с опущенным `duration` остаётся в сцене. |
| `StylizedMotionBlur` | Короткий ряд полупрозрачных поз на прошлых дробных кадрах. Для собственного силуэта передай `renderGhost(index, opacity)`. |
| `FocusEffect` | Стягивает внимание к объекту парой дуг. `size` задаёт финальный радиус. Для перевода оптического фокуса используй существующий depth-of-field pass. |
| `AnimatedArrow` | Указатель в мировом пространстве. Наконечник направлен вдоль `direction`, исходная ось +Y. |
| `FloatingIcon` | Всплывающий трёхмерный знак `star`, `diamond` или `dot`. `position` и `direction` определяют исходную точку и ось подъёма. |

## Событийное использование

```tsx
// Внутри того же ThreeCanvas, где использованы координаты линзы.
<ImpactEffect
  frame={frame} from={contactFrame} duration={22}
  position={lensContact} direction={[0, 1, 0]}
  theme="clay" color="#deb487" size={0.75}
  count={14} budget={particleAllocation}
  opacity={0.84} motion="sharp" seed="lens-contact"
/>
<MotionTrail
  frame={frame} from={launchFrame} duration={28}
  sample={lensPositionAtFrame} sampleFrom={launchFrame}
  theme="clay" size={0.11} samples={10} budget={trailAllocation}
  step={1.5} opacity={0.7}
/>
```

`sample` принимает дробный кадр и возвращает координаты в системе родителя следа. На монтажных склейках и телепортации раздели трек на два события и сбрось `sampleFrom`. Иначе след соединит пространственно несвязанные позиции.

## Контроль качества и ресурсов

Инстансы объединяют однотипные частицы в один батч, включая гранулы, дым, пыль, фрагменты удара и геометрию следа. Удерживай предел `count` постоянным в рамках события и управляй числом отображаемых элементов через `budget`. Буфер матриц выделяется один раз на смонтированный эффект, GPU получает снимок текущего кадра. Варианты рассеивания заранее получают адресуемый по индексу набор псевдослучайных величин. Декларативные геометрии и материалы освобождаются при размонтировании батча. Переданные извне `map`, `geometry` и материалы пользовательских силуэтов остаются ресурсами вызывающей сцены.

Проверяй точки запуска, пика и конца. Растягивание и эхо поз должны поддерживать читаемый силуэт. Предпочитай один плотный выброс нескольким широким полупрозрачным перекрытиям. При артефактах сортировки сократи пересекающиеся прозрачные слои, разнеси их по глубине и сохрани проверку глубины. У атмосферных карточек и локальных шейдеров нет полноэкранного буфера. Искажению фоновой картинки нужен переданный источник. Художественное размытие использует копии позы, а не дополнительные выборки всего кадра.

Открой `HyperMotionEffects` командой `npm run studio:hyper` из `video/`. Композиция 1080×1920, 30 FPS, 90 кадров объединяет 20 карточек в одном `ThreeCanvas`. Параметр `theme` переключает оформление эффектов. На кадре 27 виден световой акцент в середине прохода, на кадре 42 хорошо читаются расширившиеся кольца и следы.
