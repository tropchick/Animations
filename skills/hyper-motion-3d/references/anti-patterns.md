# Что перепоставить

| Уровень | Сюжетный пример с игрушечной полкой |
| --- | --- |
| Обычная анимация | Игрушечная коробка едет по полке, останавливается перед упором и открывается |
| Декоративное усиление | На том же движении появляются искры, краткий зум и цифра. После исчезновения искр коробка и предметы вокруг выглядят как раньше |
| Hyper Motion | Коробка пружинит на упоре. Шарнир раскрывается через одну читаемую промежуточную позу, крышка запускает эстафету среди стоящих рядом игрушек. Следящий боковой кадр раскрывает очередность, плоский блик ложится на реальную геометрию и исчезает, счётчик меняется в момент завершения этапа. На общем плане предметы остаются раскрытыми |

| Проблема в кадре | Исправление |
| --- | --- |
| Весь диапазон едет ровно из точки в точку | Добавь перенос веса, сомнение, смену опоры, короткое ускорение, перелёт и след. Дай ткани или навесным деталям отдельный ритм |
| Реакция возникает рядом с событием и сразу гаснет | Поставь источник, путь и несколько восприимчивых опор. Проиграй реакцию с задержкой по расстоянию и меняй состояние объектов по устойчивым ID |
| Камера слегка приближает всё одинаково | Поставь кадры, в которых видны механизм, география и ответ персонажа. При раскрытии крупности дай зрителю ориентир перед движением |
| Текст и FX одновременно занимают лицо | Перенеси шкалу в чистую часть кадра, эффекту дай локальное место и глубину. Сократи видимость слабой вторичной детали, сохрани основную форму |
| Перерыв заполнен только циклом атмосферы | Добавь след прошедшего события, реакцию героя или подготовку нового действия. Для намеренной паузы запиши, что зритель в ней должен прочитать |
| Изображение прыгает между материалами и оттенками целиком | Закрепи короткий контур на объекте, оставь общий свет близким по яркости, выведи контур в материал за несколько кадров |
| Не видно, чем ближний масштаб связан с дальним | Внеси один повторимый объект и его экранный путь. Закрой LOD в геометрии или облаке с предсказуемым «выходом» в следующем кадре |
