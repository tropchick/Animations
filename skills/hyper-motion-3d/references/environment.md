# Живое окружение

Поставь движение по трём планам. Ближний силуэт создаёт глубину и может закрыть монтажный разрез. В среднем плане движется герой, а фон поддерживает время и место действия. Используй для фона медленный контрастный ритм, отличный от движения героя. Оставляй участок вокруг глаз и важной детали свободным от пересекающихся траекторий.

[environment.tsx](../examples/environment.tsx) содержит функции для траекторий, растительности, облаков, реакций и мотивированных перемен освещения. Функции принимают номер кадра, компоненты могут брать текущий кадр из Remotion. Фазу движения сохраняй при переходе между планами, чтобы транспорт и прохожие оставались в своих точках мира.

| Слой | Реализация |
|---|---|
| Прохожие и транспорт | Подготовь `prepareRoute(points)` один раз. Закрытая траектория работает по кругу, `closed: false` удерживает персонажа на концах. `RouteFollower` принимает `speed` в единицах мира в секунду и стартовый `phase` в единицах расстояния. Направление рассчитано для модели лицом к `+Z`. Для более плавных поворотов проложи дополнительные точки, `turnDistance` скруглит поворот взгляда вокруг угла. |
| Деревья, трава, одежда | Смещай вершину или сустав с `windSway`, задавая корень ветки точкой вращения `WindGroup`. Общий ветер поддерживает единое направление, `seed` меняет детали. Для глины используй исходную экспозицию, для лёгких облаков можно оставить непрерывное движение. |
| Облака и дальние объекты | `driftLoop` движет объект между `from` и `to` и возвращает видимость у края цикла. Помести края за границы видимого конуса камеры, разнеси скорость и фазы. Смена плотности облаков может мотивировать мягкую перемену света. |
| Реакция статистов | `reactToEvent({frame, at, distance})` возвращает нарастающий и затухающий отклик с задержкой и ослаблением по расстоянию. Примени к наклону головы, росту света в окне или качанию флажка. Выбери реагирующие группы по сценарию. |
| Параллакс | Разнеси физические меши по глубине. Камера даст перспективный параллакс при движении. Для плоских карт используй `depthPan(cameraDelta, relativeDepth)`, уменьшая сдвиг на дальних планах. |
| Освещение | `ambientLight(from, to, progress)` возвращает цвет и интенсивность. Передай результат в имеющийся свет. Эффект поддерживает сюжет, когда меняется источник света, открывается люк или зажигается устройство. Перед серией кадров сравни тон кожи и направление тени. |

```tsx
const path = prepareRoute([[-3, 0, -5], [2, 0, -5], [2, 0, -8], [-3, 0, -8]]);

<RouteFollower route={path} speed={0.8} phase={2.4}>
  {({distance}) => <Passerby stepPhase={distance * 2.8} />}
</RouteFollower>
```

В коротком плане разведи перемещения по скорости и месту в кадре. Если важный текст возникает над героем, уводи дальние частицы и движение рядом с титром в спокойный диапазон. Канал `background` удобно направить в амплитуды ветра и реакций. При скорости перемещения, меняющейся во времени, заранее собери непрерывную дистанцию по ключам и передай её как `phase` при нулевой `speed`. Умножение номера кадра на меняющуюся скорость может сдвинуть объект скачком.

Для дальнего людского потока или повторяющихся деревьев раздели трассы по модели и обновляй трансформации внутри `InstancedMesh`. Переиспользуй геометрию и материалы, упрощай силуэты на удалении, оставляй реальные тени у героя и ближайшей опоры. [Three.js InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html) · [Three.js performance](../../threejs-performance/SKILL.md)
