# Реакции окружения и состояние мира

Сначала покажи источник и контакт. Ближние детали реагируют с небольшим сдвигом, затем отклик доходит до групп и раскрывает результат в следующем плане. Дальние объекты могут изменить форму, цвет, освещение или траекторию, сохраняя знакомые силуэты и материалы.

[world-reactions.ts](../examples/world-reactions.ts) компилирует авторские координаты, стабильные ID и правила распространения. Сэмплер возвращает долговременное `state`, временные `channels`, общую амплитуду `pulse` и текущие `hits`. Детальный фасад и упрощённая модель используют один ID, даже если монтируются в разных планах. Бери кадр состояния с общего выходного таймлайна и квантуй позу куклы после расчёта прихода волны.

```ts
const world = compileWorldReaction({
  origins: {seed: [0, 0, 0], planter: [2, 0, 0], rooftop: [0, 5, -12]},
  initial: {planter: {open: 0, color: 'ochre'}, rooftop: {open: 0, color: 'ochre'}},
  events: [
    {id: 'bloom', frame: 120, origin: 'seed', speed: 0.36, radius: 18,
      attack: 4, decay: 24, channels: {sway: 0.6, bounce: 0.3, stretch: 0.4, light: 0.8},
      persist: {open: 1, color: 'mint'}, commit: 'arrival', transitionFrames: 12},
    {id: 'night-fall', frame: 340, origin: 'rooftop', speed: 1,
      targets: ['planter', 'rooftop'], persist: {open: 0.3, color: 'ochre'}, transitionFrames: 16},
  ],
});

const {state, channels, hits} = world(frame, 'planter');
const pose = sampleReactionPose(channels, {style: 'clay', seed: 'planter', gain: 0.5});
```

- `speed` задан в единицах мира за выходной кадр. Приход равен `frame + distance / speed`. На границе `radius` состояние меняется, плавная и линейная амплитуды достигают нуля. `targets` задаёт связи между известными объектами. Для пути вдоль квартала поставь последовательные события на узлах, где важен маршрут волны.
- `attack`, `hold`, `decay` задают огибающую. `hits` содержит ID, расстояния, веса и кадры прихода. Произвольные каналы можно направлять в свет, материалы, риг, транспорт и частицы. Перекрывающиеся уровни суммируются в пределах `[-1, 1]`.
- `persist` действует после затухания. `commit` начинает изменение при приходе, на пике или после затухания. `transitionFrames` плавно меняет числа и переключает строки и логические значения в конце. Следующее событие начинает переход от текущего значения. При равном кадре порядок задаётся ID. Для возврата добавь событие сценария.
- Используй постоянное поле формы для лепестков или створок, цвет для палитры, числовой коэффициент для скорости транспорта и состояние разрушения для переключения на подготовленные фрагменты. У движущихся объектов регистрируй авторскую точку контакта на трассе. Связывай группы через одну экспозицию и очевидную причину реакции.
- `sampleReactionPose` добавляет локальное смещение, отскок, наклон и squash/stretch к авторской позе. Вертикальная деформация компенсируется по двум поперечным осям. Крепи наклон листвы к корню, деформацию куклы к опоре, подвеску транспорта к кузову. Для вторичной детали используй `elasticResponse(age, duration)` с коротким запаздыванием. У глины ограничь подъём и меняй экспозиции, в low-poly используй чистую смену плоскостей. [Покадровое время в глине](../../claymation-3d/examples/timing.ts)

Проверь кадры до импульса, у ближайшего объекта, у дальнего и после затухания. Прокрути назад и сверь каждый ID. При монтаже зритель должен узнавать источник по форме, месту, направлению, цвету или иной причинной связи.
