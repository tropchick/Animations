# Хореография одного события

`compileChoreography` проверяет исходный JSON и заранее строит окна дорожек. `sampleChoreography` вычисляет подготовку, контакт, отдачу, хвосты дорожек и лимит частиц из выходного кадра. Окна в пресетах записаны в единицах 30 FPS и пересчитываются под FPS проекта и `pace`. На них можно опереться при выборе диапазонов поз, камеры, света и эффектов. Тип меша, ось и материальный ответ выбирает сцена.

```ts
import {compileChoreography, sampleChoreography} from './choreography';
import rawPlan from './my-plan.json';

const plan = compileChoreography(rawPlan);
// Внутри композиции передай useCurrentFrame() или абсолютный кадр родителя.
const {events, intensity} = sampleChoreography(plan, outputFrame, {quality: 'final', seed: 'garden'});
```

Собранный план также даёт `voice` с интервалами реплик, `cameraTrack` для `DynamicCamera` и `poseTracks`. Ключ позиции обязателен, вращение задано в радианах, масштаб по умолчанию единичный. `sampleAuthoredPose(track, frame)` удерживает крайние ключи и применяет входную кривую между ними. `worldEventsFromPlan(plan)` переносит `reaction` с тем же ID, кадром и источником в `compileWorldReaction`; `reaction.persist` содержит поля, которые должны остаться до сценарного возврата.

Каждая активная запись содержит `cue`, `age` в выходных кадрах, `phase`, `lanes`, `seed` и `particleBudget`. Большая сцена может получать несколько активных записей одновременно. Передавай объект события по типу реакции, чтобы камера, геометрия, мир и интерфейс не расползлись по дублирующимся числам. Если событие длится дольше любой визуальной огибающей, его результат семплируется из постоянного трека. [Сохранение мира](world-reactions.md)

| Пресет `recipe` | Как поставить причинное событие |
| --- | --- |
| `layered-reveal` | Передвинь заслонку с запаздывающим шарниром. Волна света обегает торец, фонарики раскрывают глубину, камера освобождает силуэт и короткий акцент отмечает фиксацию |
| `elastic-transformation` | Сжатие на опоре, энергичное раскрытие, перелёт состояния, отдельно запаздывающие детали, небольшой ответ соседнего предмета |
| `energy-build-up` | Материал накапливает свечение, дуги сужаются к точке, камера меняет перспективу; после выпуска сначала виден новый объект, потом раскрывается реакция |
| `world-reaction-sequence` | Начни с движения источника, проведи реакцию вдоль пути, передай её на соседние группы, открой последствия широким планом |
| `scale-reveal` | Зафиксируй форму в крупном, проведи камеру через рамку, активируй другой уровень детализации и сохрани тот же ориентир |
| `counter-level-up` | Свяжи действие, отмечаемый порог, число, заполнение шкалы, новую палитру, вторичный геометрический мотив и звук на одной метке |
| `geometric-assembly` | Подводи фрагменты разными дугами к подписанным местам, защёлкни их, дай соседнему материалу и камере показать массу и готовую форму |
| `object-transformation` | Сохрани опорную деталь, разверни конструкцию по швам, на переходе покажи промежуточную форму и зафиксируй смену состояния |
| `cinematic-focus-shift` | На ближнем объекте заверши действие, подхвати движение дальнего плана, переведи на него внимание перспективой, фокусом и светом |
| `comedic-reaction` | Подготовь зрителя взглядом или позой, коротко задержи отклик, покажи локальное изменение, выдержи читаемое выражение героя |
| `environmental-ripple` | Задай пространственный фронт. По мере прихода поднимай, наклоняй или перекрашивай объекты. Дай фронту уйти в глубину и оставь новый рисунок среды |
| `material-change` | Двигай границу нового материала по форме, учитывай рисунок швов и фактуру, раскрой масштаб ответивших объектов |
| `particle-cascade` | Несколько фаз выброса идут от главной формы в среду. Объекты перекрывают частицы, обнаруживают их движением или ловят локальный свет |
| `stylized-impact` | Подготовь позу, выдели контур на контакте, продли ответ упругой формой и изменением среды. Сведи обводку в обычный материал |
| `continuous-scale-journey` | Путь камеры сохраняет направление и маркер. Новые глубинные группы раскрываются по очереди, продолжают ту же реакцию и подтверждают, где теперь находится зритель |

Для настройки слоя используй `layers: {body: [-14, 0, 38], camera: [-7, 2, 30, 0.6], hud: false}`. Три числа задают начало, вершину и конец относительно `at`, четвёртое меняет вес. Нулевая атака допустима на контакте. Спад камеры и позы может быть мягким, даже если аудио стартует точно в `at`. Отдельные окна помогают сохранять характер ткани, твёрдой игрушки, лепного реквизита или реалистичного предмета.

Драфт выделяет 128 частиц на три активных пространственных события, финал 400 на пять. `priority` отдаёт запас доминантному событию. Постоянная поза, состояние мира и кадр звука не зависят от выделения частиц. При адаптации под слабый CPU сначала уменьши плотность мелких объектов за силуэтом, затем число копий и мягких атмосферных слоёв. Сохрани крупную смену формы, фронт, который ведёт взгляд, и художественно значимый след. [Производительность](integration.md)
