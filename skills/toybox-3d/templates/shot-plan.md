# Шаблон постановки Toybox

Скопируй только поля, которые нужны конкретной сцене. В Remotion держи сюжетные точки в кадрах исходной композиции и передавай компонентам их локальный кадр или уже рассчитанный прогресс.

| Поле | Что определить |
| --- | --- |
| Действие и результат | Одно предложение, понятное при выключенном звуке. |
| Формат и хронометраж | Размер, FPS, длительность, контрольные кадры. |
| Направление и палитра | Тон основания, вспомогательный цвет, акцент, тёмный контур света, светлые плоскости. |
| Герой | Силуэт, мотив, тип поверхности, точка опоры, направление взгляда. |
| Среда | Передний план для глубины, средний для действия, задний для контекста. Две фоновые петли без конкуренции с героем. |
| Движение | Упреждение, перенос веса, контакт, объём реакции, затухание. |
| Трансформация | Исходная функция, опорная деталь, движущиеся компоненты, новый масштаб, факт завершения. |
| Камера и свет | Цель камеры на каждом плане, параметры света, кадр проверки блика и тени. |
| Графика | Текст или счёт, место относительно лица, длительность чтения, безопасная область. |
| Звук | Решающие контакты и одна пространственная атмосфера, если нужны. |
| Проверка | Кадры в начале, на пике и после движения, стоп-кадры в порядке и вразнобой, просмотр со звуком и без. |

## Короткий пример

Курьер заказывает один кофе и получает гигантскую чашку, внутри которой раскрывается крошечная терраса. Настоящая чашка появляется только после того, как курьер поверил в абсурдный результат.

| Бит | Постановка |
| --- | --- |
| Заказ | Общий план улицы и руки у кнопки. Бирюзовое окружение приглушено, тёплая кнопка задаёт фокус. |
| Контакт | Ладонь доходит до кнопки, корпус переносит вес на переднюю ногу, панель отвечает ходом пружины. |
| Раскрытие | Корпус расходится сегментами, эмалевый обод возвращается в кадр как край чашки. |
| Новый масштаб | Совпадающий обод сохраняет направление при входе в миниатюрную террасу. |
| Шутка | Взгляд курьера опускается на крошечную чашку. Камера даёт прочитать паузу и реакцию. |
