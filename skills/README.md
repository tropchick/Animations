# Скиллы для 3D-анимаций

Здесь собраны скиллы (инструкции для ИИ-агентов), которые пригодятся, чтобы делать вертикальные low-poly ролики в стиле "What if...": простые угловатые 3D-модели, мягкие тени, крупный текст поверх кадра, счётчик (HUD) сбоку и атмосферный звук.

Папки `.claude/skills` и `.agents/skills` в корне репозитория — это ссылки на эту папку, поэтому Claude Code и Codex сами находят эти скиллы.

## Пластилиновая анимация

[claymation-3d](claymation-3d/SKILL.md) — лепные куклы, миниатюрные улицы, процедурные отпечатки и покадровая игра персонажа. Включает переиспользуемые компоненты, плавный и покадровый режимы, а также 12-секундную композицию `ClayPostalStreet` для Remotion.

## Динамическая режиссура и эффекты

[hyper-motion-3d](hyper-motion-3d/SKILL.md) — камера, монтаж, визуальные эффекты, живая типографика, звук и покадровый таймлайн для вертикальных 3D-роликов. Работает поверх low-poly, claymation-3d и других стилей. Включает 24-секундную демонстрацию, сравнение одной сцены и пример на пластилиновой улице.

## Как всё связано (рекомендуемый путь)

1. **Сцена и анимация:** Remotion + React Three Fiber (Three.js). Всё пишется кодом, каждый кадр считается из номера кадра, рендер идёт без видеокарты в браузере Chromium. Текст, счётчик и звук делаются в том же проекте.
2. **Модели (по желанию):** если простых фигур мало, модель делается в Blender, экспортируется в GLB и загружается в Three.js.
3. **Звук:** эффекты и музыка генерируются через ElevenLabs (нужен ключ `ELEVENLABS_API_KEY`), потом кладутся в Remotion как дорожки.
4. **Проверка:** раскадровка (contact sheet) из отрендеренных кадров, чтобы увидеть ошибки без просмотра всего видео.
5. **Финал:** ffmpeg для сжатия и экспорта под Shorts/TikTok/Reels.

Blender тоже можно использовать как основной движок (рендер EEVEE), но в облаке без видеокарты рендер 1+ минуты будет очень медленным. Поэтому основной путь — Remotion + Three.js.

## Что сохранено

### Remotion (сборка видео, текст, звук)
Источник: https://github.com/remotion-dev/skills (версия 4.0.538). Лицензии в репозитории нет, сохранено для личного использования.

| Скилл | Зачем |
|---|---|
| `remotion-create` | Как создать проект, правила вёрстки кадра и размеры текста |
| `remotion-markup` | Главный скилл: анимация через `useCurrentFrame()`, сцены, переходы, шрифты, эффекты. Внутри `3d.md` (Three.js в Remotion), `audio.md` (звук: громкость, обрезка, высота тона), `sfx.md` (готовые звуки) |
| `remotion-interactivity` | Как строить таймлайн сцен, чтобы его было удобно править |
| `remotion-render` | Команды рендера видео и отдельных кадров |

Из `remotion-markup` убраны ненужные для нас файлы (карты, арабский текст, GIF, Lottie, озвучка, монтаж чужих видео). Ссылки на них внутри `SKILL.md` просто не откроются.

### Three.js / React Three Fiber (3D-сцена)
Источник: https://github.com/OpenAEC-Foundation/Three.js-Claude-Skill-Package (MIT).

| Скилл | Зачем |
|---|---|
| `threejs-impl-react-three-fiber` | 3D-сцена на React |
| `threejs-impl-drei` | Готовые помощники: окружение, мягкие тени, загрузка моделей |
| `threejs-impl-lighting` | Свет (солнце + небо, как на референсах) |
| `threejs-impl-shadows` | Мягкие тени и исправление артефактов |
| `threejs-impl-post-processing` | SSAO (затенение в углах), сглаживание, свечение ламп |
| `threejs-syntax-geometries` | Простые фигуры: из них собираются люди, деревья, камни |
| `threejs-syntax-materials` | Материалы, `flatShading: true` даёт гранёный low-poly вид |
| `threejs-errors-rendering` | Чёрный экран, блёклые цвета и другие поломки |

**Важно:** внутри Remotion нельзя использовать `useFrame()` из React Three Fiber (будет мерцание). Любое движение считается только от `useCurrentFrame()`. Скилл `remotion-markup/3d.md` главнее скиллов Three.js в этом вопросе.

### Blender (модели, камера, анимация)
Источник: https://github.com/CheshireJCat/blender (MIT), который основан на https://github.com/RobLe3/cc-blender-skill (MIT).

| Скилл | Зачем |
|---|---|
| `blender-cameras` | Фокусное расстояние, композиция, движения камеры (наезд, облёт) |
| `blender-animation` | Ключевые кадры, плавность, циклы, совместимость с Blender 5 |
| `blender-modeling` | Простые модели из примитивов и модификаторов |
| `blender-lighting` | Схемы света, солнечный день, интерьер |
| `blender-rendering` | EEVEE/Cycles, рендер анимации в кадры. Взята версия RobLe3, там исправлен пресет EEVEE для новых версий Blender |
| `blender-pro-workflow` | Порядок работы над сценой. Внутри `references/blender-5-compat.md` |
| `blender-export` | Экспорт моделей в GLB для Three.js |
| `animation-quality-gate` | Проверка анимации по раскадровке. Скрипт `scripts/animation_contact_sheet.py` работает с любыми кадрами, не только из Blender |

Эти скиллы написаны под свои инструменты (`blender_python` и Blender MCP). Без них тот же Python-код запускается командой `blender --background --python script.py`.

## Что отклонено и почему

- **Остальные модули CheshireJCat/blender** (реконструкция по фото, UV-развёртка, подгонка по ортографии, логотипы и т.д.) — для точного копирования объектов по чертежам, нам не нужно.
- **`blender-materials`** — в основном металл, стекло, кожа. Для low-poly хватает простых матовых цветов.
- **RobLe3/cc-blender-skill целиком** — почти то же самое, что CheshireJCat. Из него взят только исправленный `blender-rendering`.
- **emalorenzo/three-agent-skills** — про скорость сайтов и мобильных устройств, а мы рендерим видео офлайн.
- **Остальные скиллы OpenAEC** (физика, VR, WebGPU, IFC-чертежи, контролы мыши) — не нужны для ролика.
- **freshtechbro/claudedesignskills** — веб-анимации для сайтов (скролл, GSAP), дублирует уже взятое.
- **digitalsamba: acestep** — генерация музыки работает только через их скрипт `tools/music_gen.py`, отдельно бесполезен. **moviepy** — дублирует Remotion. **elevenlabs** — дублирует официальные скиллы ElevenLabs.
- **ElevenLabs: озвучка, дубляж, распознавание речи, агенты** — в роликах нет голоса, только текст на экране.
- **Remotion: карты, субтитры по речи, SaaS, загрузка видео** — не по теме.
- Отдельного готового скилла именно про low-poly стиль найти не удалось. Стиль делается так: простые фигуры + `flatShading` + мягкий свет и тени + SSAO.
