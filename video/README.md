## What if the air disappeared for 5 seconds?

Ролик 1:08, вертикальный 1080×1920, 30 кадров в секунду. Сценарий: `../scripts/what-if-air-disappeared.md`.

Готовое видео лежит в `../renders/air-gone.mp4`.

## Как пересобрать

Нужны Node.js 22, Python 3 с `numpy` и `scipy`, и ffmpeg.

```bash
cd video
npm install
npm run render      # делает звук и рендерит out/air-gone.mp4 (около получаса без видеокарты)
npm run studio      # открыть предпросмотр в браузере
```

## Хроника слизи, серия 1 «Утечка»

Озвучка сделана в ElevenLabs (голос VASKO, Multilingual v2) и лежит в `audio/voice/`. Паузы в ней вышли короткими, поэтому скрипт звука сам режет голос по словам и вставляет тишину. От этого же зависят все тайминги кадров.

```bash
cd video
pip install numpy scipy
npm run render:slime     # режет голос, делает звук и cues.json, рендерит out/slime-ep1.mp4
npm run stills -- SlimeEp1 out/stills 3 31 80   # отдельные кадры по секундам для проверки
```

| Файл | Что внутри |
|---|---|
| `audio/make_slime_audio.py` | Монтаж голоса (`PAUSES`: где и сколько тишины вставить), границы всех 23 кадров, весь остальной звук |
| `audio/voice/slime-ep1-words.json` | Время каждого слова в двух файлах озвучки (распознано один раз, чтобы не ставить распознавалку) |
| `src/slime/cues.json` | Создаётся скриптом звука: время слов в видео, кадры, огибающая голоса для экрана диктофона |
| `src/slime/camera.tsx` | Все планы камеры, дрожание «с рук» и толчки |
| `src/slime/Hall.tsx` | Зал «Ковыль»: стеклянная камера с замками, рука-манипулятор, пульт, стол Глеба, колпак, руки в перчатках |
| `src/slime/Macro.tsx` | Макро-мир: стальная поверхность с ямкой, крупинки, пыль, стенка колпака |
| `src/slime/Corridor.tsx` | Коридор с запертой дверью |
| `src/slime/Gleb.tsx` | Глеб и отдельная рука в перчатке для крупных планов |
| `src/slime/screens.tsx` | Экраны: диктофон с волной голоса, счётчик образцов, микроскоп, страница блокнота |
| `src/slime/Overlay.tsx` | Русские надписи, рамка микроскопа, боке, виньетка, зерно, финальная карточка |

## Хроника слизи, серия 2 «Первые сутки»

Голос собран из трёх дублей ElevenLabs: основной, «Я закрыл. Сам...» и «Я ждал... тут пол мягкий». Какие слова из какого дубля брать, задаёт `PIECES` в скрипте звука. Слова Савельевой звучат как из рации.

```bash
cd video
npm run render:slime2    # голос, звук и cues.json, потом рендер кусками в out/slime-ep2.mp4 (~80 минут)
npm run stills -- SlimeEp2 out/stills 2 30 61 84
```

| Файл | Что внутри |
|---|---|
| `audio/slime_lib.py` | Общее для всех серий: склейка голоса из дублей, синтез звуков, сведение и громкость |
| `audio/make_slime_ep2_audio.py` | Монтаж голоса (`PIECES`, `PAUSES`), границы 20 кадров, звук серии |
| `src/slime/scene.ts` | Что следующие серии меняют в зале первой серии (номер записи, тонущий колпак, исчезнувший стол, дверь) |
| `src/slime/ep2/World.tsx` | Какая сцена в каком кадре, макро с крупинками, свет и туман по времени суток |
| `src/slime/ep2/camera.tsx` | Планы камеры второй серии |
| `src/slime/ep2/Mass.tsx` | Серая масса: гладкая кожа с дрожащими гранями, холмы, наплывы на ножках |
| `src/slime/ep2/HallEp2.tsx` | Масса на полу зала, Глеб с телефоном, у рычага, в окошке, рука на двери |
| `src/slime/ep2/Campus.tsx` | Двор, «Ковыль», «Осока», третий корпус с крышей, коридор с рацией, утренние холмы, город |
