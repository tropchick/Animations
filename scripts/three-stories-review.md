# «Три истории»: самопроверка

## Итоговый формат

1080×1920, 30 fps, 1711 кадров, 57,033 с. Кадр 0 — композиция обложки; история начинается с кадра 1. Оригинальная короткая запись VASKO, без новой озвучки, изменения скорости и музыки. В исходной паузе после первой истории добавлено 4 с для наклейки и начала грозы. Финальный вопрос появляется после окончания речи.

## Черновик и пять слабых мест

Черновик 720×1280 отрендерен целиком через `tools/render-chunks.sh`: `video/out/three-review/draft-720.mp4`. Из него извлечены 57 кадров, по одному в секунду: `draft-frames/`. Раскадровка собиралась через `tools/sheet.sh` (страницы по 16 кадров).

Проверка черновика и последующее декодирование экспортов выявили и привели к исправлению пяти важных проблем:

1. **Начало закрывал бетонный портал.** В первых кадрах вместо автобуса была видна стена. Камера перенесена на другую сторону; начало проверено на 0,033 / 0,333 / 0,633 с. Временная плоская вставка удалена, в окончательной версии весь хук снова 3D.
2. **Наклон персонажей читался как отклонение назад.** Исправлен знак наклона исходного рига: голова Вити выходит из открытого окна, физик наклоняется к открытому участку ускорителя. Трубы разведены шире, голова остаётся в просвете. Контакт черепа и бетона уточнён.
3. **Силуэты и детали терялись.** Исправлены перекрытия салона задней стенкой, тесный ракурс наклейки, слишком крупный рентген, смещённое за край тело в полёте. Воронка заменена с отдельных колец на цельную поверхность со спиралями; на обложке увеличены человек и лампа.
4. **Слабая связность торнадо.** До крупного плана удара Мэтт и торшер теперь поднимаются над полом вместе с обломками. После полёта Мэтт сначала лежит, затем садится и идёт к свету. После удара лицо скрыто.
5. **Разрывы фраз и мерцающие конструкции.** Караоке разбито по смыслу: «400 метров» и «и защитил диссертацию» остаются вместе. Четыре пары наложенных граней в каркасе ускорителя устранены разделением стоек и верхней балки.

## Проверки финального экспорта

Проверяются именно декодированные кадры MP4: обе стороны всех монтажных границ, первый/последний кадр, по пять кадров вокруг каждого главного контакта. Скрипт `video/tools/three-audit.py` сохраняет 113 кадров границ и контактов плюс 57 кадров по секундам. Технические параметры подтверждаются ffprobe.

Проверка z-fighting: `cd video && npm run zcheck -- ThreeStories 0.5`. Для всех камер включён `logarithmicDepthBuffer: true`. После устранения пересечений каркаса полный проход 115 кадров дал 0 FLICKERS и 0 risky. Финальный повтор после последних изменений сохраняется в `video/out/zcheck-ThreeStories.json`.

Звуковая карта: `scripts/three-stories-sync.md`. Пики 24 эффектов выставлены по времени истории с добавкой 1/30 с. Скрипт `three-sync-check.py` сравнивает фактически декодированный AAC с исходным финальным WAV в каждом из этих мест; результат сохраняется в `video/out/three-review/final-sync.json`. Это проверяет, что экспорт не внёс сдвига звука.

## Ограничения художественной реконструкции

- Рентген, разрушение вагончика и воздушные потоки намеренно стилизованы; это наглядная реконструкция, а не медицинская или инженерная симуляция.
- Звуки полностью синтезированы. Шум испуга в салоне условный: отдельных записанных человеческих криков нет. Для более документального звука можно заменить его коротким лицензированным шумом испуга нескольких пассажиров.
- Паралич и потеря слуха показаны подписью и жестом со спины: травмированное лицо после удара не показывается.
- Под баннер оставлена незаполненная полоса y=720…1200 в 21,883–29,083 с MP4; баннер должен добавить владелец.

Платные генеративные API не использовались. Git commit/push агентом не выполнялись.

## Результат последнего прохода

- Проверен окончательный файл после полного рендера через `render-chunks.sh` и ремультиплексирования faststart без перекодирования изображения.
- ffprobe: 1080×1920, 30/1 fps, 1711 кадров, 57,033333 с, H.264 + AAC 48 кГц.
- Z-check через 0,5 с: 115 кадров, 0 FLICKERS, 0 risky; проход 232 с.
- Проверены 113 декодированных кадров границ/контактов, начало, конец, 57 кадров по секундам. Итоговые листы — `video/out/three-review/approved/`.
- Сравнение AAC с WAV в 24 точках: максимальный сдвиг 0.0 мс, минимальная корреляция 0.99326.
- Окончательный хук полностью 3D; временная плоская вставка отсутствует.

Полное декодирование FFmpeg завершилось без ошибок. Измеренная громкость готового AAC: −15,05 LUFS, true peak −2,32 dBTP, LRA 6,9 LU.
