# «Что если движуха закончится?» — сценарий v1

Формат как у GTA-цепочки и шаурмы: low poly, вертикально 1080×1920, русская озвучка (ElevenLabs v4, голос VASKO, один дубль), караоке-субтитры, сверху плашка с днём. Каждый шаг вытекает из предыдущего, всё сильно приукрашено. Длина около 60 с.

Слово «война» нигде не звучит и не пишется, только «движуха». Никаких солдат, техники, флагов, карт и реальных политиков. Страна в кадре просто «страна», без названий.

Обложка (кадр 0): мужик в майке на кухне с отвисшей челюстью, в руке падает кружка, на телевизоре «СРОЧНО: ДВИЖУХА ВСЁ», за окном салют. Текст: «Что если движуха закончится?»

## Звук
- Хук: звон разбитой кружки, крики соседей с балконов, салют.
- Щелчки табло (сцены 2 и 11), гул аэропорта, треск фанеры, шуршание спальников, вздох грустного продавца ВПН, гул прилёта, звон кассы, гул катка, звон телефона с зарплатой, гомон очереди у посольства.
- Финал: тишина за столом, звон ложки о чашку, потом удар кулаком по столу.
- Музыки нет (правило для «Что если»), только звуки.

## Правила
- Только слово «движуха», чтобы видео не порезали за тему.
- Без брендов: бургерная, ТЦ, телефоны без логотипов.
- Обложка = кадр 0, текст ≥ 34 px, проверка мерцания перед рендером.
